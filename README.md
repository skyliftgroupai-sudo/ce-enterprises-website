# C.E. Enterprises Indy Roofing Siding & Restoration — Website

Static site generated by `build.py` (Python 3, no dependencies). Keyword landing pages live in `pages_seo.py` — add or edit a page there and rebuild.

## Deploy (GitHub + Vercel)
1. Push this folder to a new GitHub repo.
2. Vercel → New Project → import the repo.
3. Settings: Framework = Other · Build Command = `python3 build.py` · Output Directory = `public` · Install Command = `echo skip`
4. After the custom domain is connected, add env var `SITE_URL=https://yourdomain.com` and redeploy (sets canonicals, sitemap, RSS).

`vercel.json` proxies the Google Business Profile photos through `/p/<name>-<width>.jpg` so they load from the site's own domain.

## Add a blog post
Drop a JSON file in `posts/` (fields: slug, date YYYY-MM-DD, title, desc, kw, photo [key from P in build.py], body [HTML]) and push. The blog index, `/feed.xml` (RSS for Blotato) and `/sitemap.xml` update on build.
